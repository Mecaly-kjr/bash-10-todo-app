# 🏷 Bash To-Do App

A Bash command-line application for managing daily tasks directly from the terminal.

---

## 📌 Problem Statement

Developers need a simple way to organize and track daily tasks without opening another application.

---

## 🎯 Project Goals

- Add and list tasks.
- Set task priorities.
- Mark tasks as completed.
- Delete tasks.
- Store tasks locally.

---

## 🛠 Tech Stack

- Bash
- Ubuntu Linux
- Git & GitHub
- ShellCheck
- AWK

---

## 🖥 Features

- Add tasks with priorities.
- List tasks by priority.
- Mark tasks as done.
- Delete tasks.
- Automatic task IDs.
- Error handling.
- Custom storage with `TODO_FILE`.

## ⚙ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/Mecaly-kjr/bash-10-todo-app.git
cd bash-10-todo-app
```

Make executable and run:

```bash
chmod +x todo.sh
./todo.sh
```

---

## 🚀 How to Run

```bash
./todo.sh add "Finish grade report"
./todo.sh add -p high "Submit Day 9 fixes"
./todo.sh list
./todo.sh done 1
./todo.sh delete 2
./todo.sh help
```
